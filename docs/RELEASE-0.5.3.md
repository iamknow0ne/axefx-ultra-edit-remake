# AxeFX Ultra Edit Remake 0.5.3 beta

Read the Ultra library once and keep it on your Mac. Successfully read slots survive restarts and disconnects, with names, search and offline previews available immediately.

- Every completed slot is saved atomically, including partial scans and bank backups.
- Refresh the full library, a bank or filtered results when needed. Live recall and verified Store refresh their slot.
- Cache profiles follow MIDI input/output identity, channel and protocol; the library shows the last cache time.
- Corrupt cache slots are isolated and can be re-read. Live recall still reads the device before switching.
- Includes 0.5.2 double-click recall, Previous/Next navigation and silent connection health checks.

Changing hardware behind the same MIDI ports cannot be detected by serial number; refresh after doing so or editing stored presets on the front panel.

Apple Silicon development beta; ad-hoc signed, not Apple-notarized. See [installation](INSTALLATION.md), the [user guide](USER-GUIDE.md) and [verification](VERIFICATION-0.5.3.md).
