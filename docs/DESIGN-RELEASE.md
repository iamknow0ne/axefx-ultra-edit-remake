# Release presentation

## Direction

A native studio utility for a real rack processor. The README leads with an actual production view and practical editing workflows. The installer uses the familiar app → Applications interaction. Documentation must remain readable offline and make hardware evidence limits visible near the download.

## Tokens and layout

- Graphite `#191d20`, raised panels `#24292d`, off-white `#edf0ed`, muted text `#b4bcbf`, amber `#e5ad61`.
- System sans-serif for prose/navigation; system monospace only for addresses, raw values and code.
- README: compact icon/title/badges, full-width editor screenshot, comparison table, paired workspace images and guide index.
- Manual: maximum 1,080 px reading area, generous line height, clear tables, responsive images, visible keyboard focus and no motion.
- DMG: 720 × 540 window, graphite title band, light installation area, original amber arrow, two primary icons and separate help/documentation icons.

## Review

Production-view renders were inspected for readable control labels, real artwork, visible connections, plot legibility and honest offline state. Synthetic names/fixtures prevent exposure of private sounds. The cabinet screenshot is the first viewport of the scrollable tool; further options remain below it in the actual app. No fabricated hardware-connected state or decorative dashboard metrics are used.

The manual and DMG receive a separate visual review after generation. Basic readability/focus checks do not amount to an exhaustive accessibility audit. The visual direction reuses the product's graphite/amber studio language rather than unrelated marketing styling.
