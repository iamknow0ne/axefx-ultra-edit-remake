# Interactive routing and device library

Desktop interaction refactor for musicians editing a physical Axe-Fx Ultra. Direction: Native macOS Utility with a studio patch-bay canvas. Retain the existing graphite StudioTheme background/panel/raised surfaces, off-white text, muted secondary labels and amber selection/cables; red only for invalid drops. Apple system type fits the native editor: 10 pt section/cell labels, 11 pt help, 12 pt actions; monospaced slot numbers. Spacing 4/8/12/20 pt, 4 pt block radius, 20 pt port targets. No decorative animation; direct pointer-following feedback also works with reduced motion.

The hardware's 4 by 12 grid remains above the effect inspector. Drag block bodies to empty cells, swap occupied cells without losing parameter records, and show a translucent moving block plus the target outline. Same-column moves carry their cables; cross-column moves reject incompatible links unless Option is held to explicitly detach them. Occupied-cell swaps retain wiring at the two positions. Cables join visible input/output sockets; drag a cable to reroute its destination, select and Delete to disconnect. Escape cancels. Context menus supply non-drag movement and routing alternatives. Live grid edits capture a fresh recovery preset, upload only the edit buffer, and verify the full payload before enabling Undo/Redo. Offline drafts use the same grid transformations.

Library gets Device / On this Mac sources. Device slots retain their addresses even when names or contents are duplicates. Bank filters cover A 0–127, B 128–255, C 256–383; numeric search can jump outside the selected bank. Stored-preset reads must not select programs or replace the live edit buffer. Read progress and cancellation are explicit. Imported bank files retain absolute slot addresses.

Validation: pure grid/address boundary tests; model integration for history, stale edits, read failure, cancellation and slot identity; physical Ultra readback including 130 and C-bank boundary; native UI drag, cable editing, bank browsing and visual review. Tradeoffs: fixed hardware topology; full-preset routing changes take longer than small parameter edits; no persistent slot writes in acceptance.
