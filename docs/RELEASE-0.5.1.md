# AxeFX Ultra Edit Remake 0.5.1 beta

Ultra Edit is now **AxeFX Ultra Edit Remake**. This release updates the app name, executable, installer, documentation, screenshots and repository address together, and adds a responsive GitHub Pages landing page with a browsable manual.

Your existing library, snapshots, drafts and preferences remain available. The bundle identifier and Application Support folder are unchanged. Quit the old app before installing the renamed app, then remove the old Ultra Edit.app to avoid keeping two launchable versions.

## Download

Choose `AxeFX-Ultra-Edit-Remake-0.5.1-arm64.dmg` for the installer with offline documentation, or the matching ZIP for the app alone. SHA-256 checksums and corresponding third-party source accompany the release.

## Status

Apple Silicon; macOS 13+ deployment target. Independent development beta, ad-hoc signed and **not Apple-notarized**. See the [installation guide](INSTALLATION.md) for first launch.

Hardware behavior is unchanged from 0.5.0. The [0.5.0 verification record](VERIFICATION-0.5.0.md) remains the hardware evidence; this branding release does not claim new hardware coverage. NAM response extraction captures filtering only, and direct cabinet transfer remains experimental. Firmware updating is excluded.
