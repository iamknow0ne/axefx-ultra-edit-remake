# 0.3 workbench extension

Native macOS utility for musicians editing an Ultra. Retain the 0.2 graphite rack, copper selection, SF system labels and monospaced values. Colors and spacing come from StudioTheme; no additional visual palette. Compact 6-point corners, 8/12/16/24-point spacing, separators rather than a dashboard of cards. No decorative animation.

Main editor remains the primary surface. A Tools menu opens a separate workbench sheet with Effect Settings, Setlist, Cabinet Lab and Rig Sheet sections. Offline Draft is an explicit state in the preset toolbar with Save Copy, Undo, Redo, and Return to Ultra. The cabinet page centers on the impulse waveform and frequency response, with preparation controls alongside. Persistent draft recovery is distinct from hardware state. All hardware changes retain backup and readback verification.

Accessibility: visible labels, native buttons/pickers/sliders, keyboard undo/redo, selectable numeric summaries, text alternatives for plots, no state communicated only by color. Show errors and empty states within the tool. Test at 1120px minimum window width and normal desktop size.
