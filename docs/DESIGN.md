# AxeFX Ultra Edit Remake design

A native macOS utility for the Axe-Fx Ultra: select a block in the 4 × 12 hardware grid, read its controls, edit, and back up a preset. High information density and accurate device state take priority.

System typography (13 pt controls, 11 pt secondary labels, 20 pt preset name), monospaced MIDI diagnostics. System window/control backgrounds support light and dark mode; muted green accent recalls the Ultra display. Spacing 4/8/12/16/24; grid blocks radius 4; standard native button corners; no custom shadows or decorative animation. SF Symbols only where useful, alongside text labels.

Layout: compact connection toolbar, preset strip, 4 × 12 grid, effect sidebar and parameter inspector, bottom connection/error status. Numeric sliders and enumerated menus use recovered definitions. Unread controls display “Not read”; no guessed values appear as device state. Hardware formatted responses take precedence over legacy profile estimates. Offline inspection is explicitly labelled.

Quality gate: keyboard labelled controls, scrollable inspectors, minimum usable window, visible errors and connection timeout, no glow/gradients/cards. Design readiness 10/10. Final visual scores recorded in verification notes after inspection.
