# AxeFX Ultra Edit Remake 0.5.4 beta

Legacy SysEx collections now import more reliably. Gen-1 Standard-tagged tones/banks are accepted for the Ultra, and cabinet impulses are recognized separately instead of failing the preset importer.

- Import 512- or 1024-sample cabinet SysEx into a persistent local cabinet library.
- Open WAV or cabinet SysEx directly in Cabinet lab; inspect imported cabinets from its menu.
- Mixed selections retain compatible files and report unsupported filenames, including other Axe-Fx generations.
- Imported tones appear under On this Mac, with filters reset so they are visible. Presets use their embedded names.
- Import up to 4096 files from a folder's top level.

Importing remains local. Cabinet upload still requires a separate explicit slot-replacement confirmation. No automatic conversion of Axe-Fx II/later presets or legacy effect-block files is claimed.

Apple Silicon development beta; ad-hoc signed, not Apple-notarized. See [installation](INSTALLATION.md), [usage](USER-GUIDE.md) and [verification](VERIFICATION-0.5.4.md).
