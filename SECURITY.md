# Security and private data

For a sensitive report, use GitHub's private vulnerability reporting if enabled, or contact the repository owner through a channel you already share. Do not put credentials, personal device dumps or undisclosed vulnerabilities in a public issue. No private reporting address is invented or implied here.

Include the version, reproducible steps and a minimal non-sensitive file when possible. NAM models and SysEx files are parsed as data, but only open files you trust. The helper is a separate process, not a security sandbox.

The application processes locally and includes no account, cloud converter or telemetry transport. Local logs and backups can contain preset names/settings. Review them before sharing. The current download is a development beta with ad-hoc signing; Developer ID/notarization remain release gates.
